HTML (1991 - Creación del lenguaje)

Tim Berners-Lee, un científico británico, creó HTML en 1991 mientras trabajaba en el CERN. Su idea era desarrollar un sistema para compartir información entre científicos de todo el mundo, lo que dio origen a la World Wide Web. La primera versión de HTML tenía solo 18 etiquetas.

CSS (1996 - El nacimiento del diseño web moderno)

Antes de CSS, los diseñadores web tenían que usar tablas y etiquetas para dar estilo a las páginas. Håkon Wium Lie propuso CSS (Cascading Style Sheets) en 1994, y en 1996 el W3C lo aprobó como estándar. Esto permitió separar el contenido de la presentación, revolucionando el diseño web.

JavaScript (1995 - Creado en solo 10 días)

Brendan Eich desarrolló JavaScript en solo 10 días en 1995 mientras trabajaba en Netscape. Originalmente se llamó Mocha, luego LiveScript y finalmente JavaScript para aprovechar la popularidad de Java (aunque no están relacionados). Hoy en día, JavaScript es el lenguaje más utilizado en el desarrollo web.
